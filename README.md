# Анкета Анона (Ultimate Vanga Edition)

Интерактивная, динамическая анкета для создания персонажа или самопрезентации, вдохновленная классическими форматами имиджборд. Написана на чистом HTML, CSS и JavaScript.

## ✨ Возможности

- **Единый визуальный стиль:** Все интерактивные элементы (шкалы, параметры, перки, достижения, мировоззрение) выполнены в виде кликабельных патчей-стрелок.
- **Интерактивное рисование:** Возможность дорисовать детали прямо поверх SVG-шаблонов тела (Мужской / Женский) с помощью кисти, ластика и функции отмены.
- **Умные текстовые поля:** Блоки "Вкусы и предпочтения" автоматически расширяются по высоте при вводе текста (с ограничением в 1500 символов и красной подсветкой при превышении лимита).
- **Автосохранение:** Все введенные данные, рисунки и настройки автоматически сохраняются в `localStorage` браузера. При перезагрузке страницы ничего не потеряется.
- **Экспорт в JPG:** Кнопка "Сохранить как JPG" генерирует высококачественный скриншот заполненной анкеты (с корректным рендерингом текстовых полей и скрытием служебных кнопок).

## 🚀 Как использовать

1. Откройте страницу в любом современном браузере.
2. Заполните поля, кликая по патчам и вводя текст.
3. При необходимости дорисуйте детали на фигурках в центре.
4. Нажмите **"📷 Сохранить как JPG"**, чтобы скачать готовое изображение.

## 🛠 Технологии

- HTML5 / CSS3 (CSS Grid, Flexbox, CSS Variables)
- Vanilla JavaScript (ES6+)
- [html2canvas](https://html2canvas.hertzen.com/) (для экспорта в изображение)
